# Woodblock prints

Placeholders. These are Utagawa Kuniyoshi's *One Hundred and Eight Heroes of the
Popular Water Margin* (c. 1827–1830) — long in the public domain, and the right
subject, but they are stand-ins for licensed or original artwork. Replacing them
is tracked in the plan's open dependencies alongside the 108 hero portraits.

Sources live in `v2/design/samples/`, which ships nothing; these copies are what
the app bundles.
